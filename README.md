# 🛒 Supermercado Online - Control de Stock y Gestión de Usuarios

## 📌 Descripción General
Este proyecto es una **aplicación web** para la gestión integral de un supermercado.  
Permite **controlar el stock de productos**, **administrar usuarios con diferentes roles** (Administrador y Cliente) y ofrecer a los clientes la posibilidad de **ver los productos disponibles** desde una interfaz moderna y simple.

El objetivo es digitalizar el manejo del supermercado, optimizando el control de inventario, las operaciones de venta y la experiencia del usuario final.

---

## 🚀 Características Principales

### 👤 Roles de Usuario
- **Administrador**
  - Agrega, edita y elimina productos.
  - Controla el stock disponible.
  - Gestiona usuarios y roles.
  - Visualiza estadísticas o reportes de stock.

- **Cliente**
  - Visualiza los productos disponibles.
  - Consulta precios, categorías y detalles.
  - (Opcional) Puede registrarse, iniciar sesión y realizar pedidos.

---

## 📦 Funcionalidades del Sistema

| Módulo | Descripción |
|--------|--------------|
| 🧾 **Gestión de Productos** | CRUD completo de productos (crear, leer, actualizar, eliminar). |
| 📊 **Control de Stock** | Actualización automática al realizar ventas o ingresos. |
| 👥 **Gestión de Usuarios** | Sistema de autenticación con roles y permisos. |
| 🛍️ **Catálogo Público** | Los clientes pueden ver los productos disponibles. |
| 🔔 **Alertas** | Notificaciones por bajo stock (opcional). |

## 🛠️ Tecnologías Utilizadas

### Backend
- **ASP.NET Core Web API** o **Node.js + Express**
- **Entity Framework Core** o **Sequelize**
- **JWT** para autenticación de usuarios
- **SQL Server** / **MySQL** / **PostgreSQL**

### Frontend
- **React + TypeScript**
- **Tailwind CSS** o **Bootstrap**
- **Axios** para la comunicación con la API
- **Zustand** o **Redux** para manejo de estados globales
